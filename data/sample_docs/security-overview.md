# Security overview (sample)

## Access control

All workforce accounts require **MFA** on VPN and email. Contractors receive limited roles that expire automatically after **90 days** unless renewed by the security team.

## Data handling

Customer data must stay inside approved regions. Copying production data to laptops is **prohibited** unless encrypted with the corporate standard.

## Incident response

Report suspected incidents to **security@example.com** within **1 hour** of discovery.
